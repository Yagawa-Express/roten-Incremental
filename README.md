# roten-Incremental

露天掘りインクリメンタル データパック「**露天インクリメンタル**」

指定されたチャンクを丸ごと掘り尽くすほど、ツルハシが強くなっていく放置・育成系データパックです。

---

## 導入

1. このリポジトリのフォルダごと（`pack.mcmeta` と `data/` が入ったまま）ワールドの `datapacks/` に置く
2. ワールドに入る、または `/reload`
3. **オーバーワールドで鉄のツルハシをクラフト** するとゲーム開始

`pack.mcmeta` は `min_format: [101, 1]` / `max_format: [107, 1]` を指定しています。

---

## 遊び方

### 1. 露天ツルハシ

鉄のツルハシのレシピが上書きされていて、クラフトすると **露天ツルハシ**（壊れない・強化されていく専用ツルハシ）が出てきます。
耐久は毎ティック自動修復されるため実質無限です。

### 2. 指定チャンクを掘り尽くす

* 開始時、プレイヤーの近くの **ランダムな 1 チャンク** が指定されます
* 指定チャンクは **パーティクルの線（4 辺 + 4 隅の柱）** で囲まれます
* そのチャンクの **岩盤の上（y=-58）から建築上限（y=319）までを全て空気にする** と「掘り終わり」
  * 水・溶岩・木・草も全て取り除く必要があります
* 掘り終わると、そのチャンクから **ランダムな方向に 1 チャンク空けて、次の 3 チャンク** が指定されます

### 3. 強化ツリー

累計チャンク数で強化が解放されます。

| 累計チャンク | 強化 |
| --- | --- |
| 1 | 効率強化 I |
| 3 | 効率強化 II |
| 5 | 効率強化 III |
| 7 | 効率強化 IV |
| 9 (3×3) | 効率強化 V |
| 16 (4×4) | 2×2 マス掘り／**見た目が金のツルハシに** |
| 25 (5×5) | 幸運 I |
| 36 (6×6) | 幸運 II |
| 49 (7×7) | 幸運 III |
| 64 (8×8) | 3×3 マス掘り／見た目がダイヤに |
| 81 (9×9) | 4×4 マス掘り |
| 100 (10×10) | ガチャ解放 |
| 121 (11×11) | 鉱石 → ガチャコイン自動変換（ON/OFF 可） |
| 144 (12×12) | 5×5 マス掘り／見た目がネザライトに |
| 169 (13×13) | 2 秒ごとに自動採掘 |
| 196 (14×14) | 1 秒ごとに自動採掘 |
| 225 (15×15) | 0.5 秒ごとに自動採掘 |

**マス掘り**は、露天ツルハシで 1 ブロック壊したとき、視線の先を中心に N×N の面をまとめて掘る機能です。
上下を向いていれば水平な板状に、横を向いていれば垂直な面状に掘れます。
**指定チャンクの中でだけ**有効なので、拠点や他人の建築を巻き込むことはありません。

**自動採掘**は、露天ツルハシを手に持っている間、視線の先を一定間隔で勝手に掘ります。

### 4. メニューとガチャ

**ポーズ画面（Esc）に「露天インクリメンタル」ボタン**が追加されます。`/trigger roten_ui set 1` でも開けます。

```
露天インクリメンタル
├─ ツルハシ強化ツリー！   … 解放済みは「Nチャンク！」、次の目標は「Nチャンク...」、それ以降は「？」
├─ 運ゲー？               … 81 チャンクで「ガチャ？」、100 チャンクで「ガチャ！」に変化
│   └─ ガチャ！
│       ├─ ガチャコイン！   … 所持コイン一覧
│       ├─ ガチャを回す！   … コインを 1 枚使って回す
│       └─ 確率配分！       … 排出率
└─ 鉱石自動変換の設定     … 121 チャンク以降のみ表示
```

**ガチャコイン**は 5 種類（コッパー / アイアン / ゴールド / ダイヤモンド / プラチナ）。
1 チャンク掘り終えるごとに配布され、上位ほど出にくくなっています。
121 チャンク以降は、インベントリ内の鉱石を自動でコインに変換できます（種類ごとに ON/OFF）。

| 変換 | レート |
| --- | --- |
| 生の銅 → コッパー | 8 : 1 |
| 生の鉄 → アイアン | 8 : 1 |
| 生の金 → ゴールド | 4 : 1 |
| ダイヤモンド → ダイヤモンド | 2 : 1 |
| ネザライトの欠片 → プラチナ | 1 : 1 |

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/trigger roten_ui set 1` | メニューを開く（全プレイヤー可） |
| `/function roten:menu` | メニューを開く（OP） |
| `/function roten:reset` | 進行状況を全てリセット（OP） |
| `/function roten:skip` | 指定チャンクをやり直す（OP・掘れないブロックで詰んだ時用） |
| `/function roten:give` | 露天ツルハシを配り直す（OP） |

## 仕組み（実装メモ）

### チャンク判定

指定チャンクは `minecraft:marker`（タグ `roten_chunk`、チャンク北西角・y=-64）で表現しています。
掘り終わり判定は `execute if blocks ... masked` を 4 段（各 16×16×120 ブロック＝上限 32768 以下）に分けて行います。
`masked` は「元領域の空気以外のブロックだけを比較する」ため、比較先が完全な空気の領域なら
**「元領域が全て空気か？」の判定**になり、ブロックが 1 つでも残っていれば即座に失敗する軽い処理になります。

その比較先として、**ワールド座標 (-30000, -30000) のチャンクを 1 つ強制読み込みし、y=-58〜61 を空気で埋めています**
（`roten:init_ref`）。このチャンクは判定用の作業領域なので触らないでください。

### 進行度

進行度（累計チャンク数・強化ティア・指定チャンク）は **ワールド共通** です。マルチプレイでは全員で 1 つの露天掘りを進めます。
ガチャコインと自動変換の ON/OFF だけはプレイヤーごとです。

### ブロック破壊の検知

露天ツルハシは `minecraft:unbreakable` の不可壊アイテムです。耐久が減らないので、
vanilla にブロック破壊のトリガーが無い問題を「照準の追跡」で解決しています（`roten:pickaxe/watch`）。

1. 毎ティック、視線の先の最初の不透過ブロックの座標をプレイヤーのスコアに記録する
2. 次のティックで、そのブロックが消えていたら「掘った」と判定する
3. 消えたブロックそのものを中心に N×N を掘る

記録より先に判定するので、自分の範囲掘りが連鎖することはありません。
2x2 が解放される 16 チャンク以降しか動かないので、序盤の負荷もかかりません。


### ダイアログ

ボタン名が進行度で変わる必要があるため、ダイアログは **マクロ関数から `/dialog show` にインライン SNBT を渡して動的に組み立て**ています
（`roten:ui/show` ほか）。ポーズ画面に出る `roten:menu` だけは静的なレジストリ定義です。

## ファイル構成

```
pack.mcmeta
data/minecraft/
  recipe/iron_pickaxe.json          鉄のツルハシのレシピ上書き（結果を露天ツルハシに）
  tags/function/{load,tick}.json
  tags/dialog/pause_screen_additions.json   ポーズ画面にメニューを追加
data/roten/
  advancement/{craft,mined}.json    クラフト検知 / ブロック破壊検知
  dialog/{menu,rates,luck_locked,gacha_locked}.json   静的ダイアログ
  tags/block/{transparent,protected}.json  レイキャスト透過 / 破壊禁止ブロック
  item_modifier/repair.json, sync/t1..t17.json         ティアごとのツルハシ性能
  loot_table/gacha/{copper,iron,gold,diamond,platinum}.json
  function/
    load, init, init_ref, tick, menu, reset
    tick/     every5(パーティクル), every20(判定・同期・変換), outline, auto
    chunk/    start, spawn, next_group, next_step, scan, cleared, reward
    pickaxe/  on_craft, on_mine, sync, area_mine, ray, hit, break_xz/xy/zy, break_one
    upgrade/  check, do, announce, labels
    ui/       dispatch, show, open_root/tree/luck/gacha/coins/roll/convert
    gacha/    roll, roll_*, toggle, t1..t5, convert, conv_*
```

## 注意

* オーバーワールド前提の高さ（y=-58〜319）で判定しています。ネザー／エンドでクラフトしても開始しません。
* 指定チャンクに survival で壊せないブロック（エンドポータル枠など）が含まれて詰んだ場合は `/function roten:skip` で指定をやり直せます。
* 掘り終えたチャンクは `roten:main done` に記録され、同じチャンクが再指定されないようになっています。
* 判定用に (-30000, -30000) のチャンクが強制読み込みされ、一部が空気で置き換えられます。
* マス掘り・自動採掘は `#roten:protected`（岩盤・チェスト・看板・ベッドなど）を壊しません。
