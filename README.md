# roten-Incremental
roten Incremental

計画

## 露天掘りのデータパック「roten Incremental」## マイクラ26.2
鉄つるはしを作成すると、壊れないつるはしが出てくる
そのつるはしで掘る。
ランダムに指定された1チャンクを掘り終わる。
指定されて掘り終わったチャンクから、ランダムな方向に1チャンク空けて、隣に次の3チャンクが指定される。
指定チャンクは、パーティクルの線で囲まれている。
## ガチャ機能は、ダイアログで実装。
メニューからダイアログに行ける。
ダイアログの名前は、「露天インクリメンタル」です。
開いたら、二つのボタンがあります。
「ツルハシ強化ツリー！」と「運ゲー？」です。
「ツルハシ強化ツリー！」は、開くと、一つ目のボタンに「１チャンク...」となっています。
達成すると、「1チャンク！」になります。
そうすると、次の「？」の名前が変わり、「3チャンク...」となります。そして、達成すると「3チャンク！」になります。
「運ゲー？」は、81チャンクが掘り終わったとき、「ガチャ？」と言う名前に変更されます。
「ガチャ？」は、100チャンクが掘り終わったとき、「ガチャ！」に変更されます。
「ガチャ！」を開くと、「ガチャコイン！」と「ガチャを回す！」と「確率配分！」が出てくる。
「ガチャコイン！」を開くと、「コッパーガチャコイン」、「アイアンガチャコイン」、「ゴールドガチャコイン」、「ダイヤモンドガチャコイン」、「プラチナガチャコイン」のボタンが出てきます。
## 強化方法

* 1チャンク　効率強化1
* 3チャンク　効率強化2
* 5チャンク　効率強化3
* 7チャンク　効率強化4
* 9チャンク（3×3）　効率強化5
* 16チャンク（4×4）　2×2マス掘り　こっから見た目が変わる。
* 25チャンク（5×5）　幸運1
* 36チャンク（6×6）　幸運2
* 49チャンク（7×7）　幸運3
* 64チャンク（8×8）　3×3マス掘り
* 81チャンク（9×9）　4×4マス掘り
* 100チャンク（10×10）ガチャを解放
* 121チャンク（11×11）指定した鉱石を自動でガチャコインに変換。ONとOFFが可能。
* 144チャンク（12×12）　5×5マス掘り
* 169チャンク（13×13）　2秒ごとに5×5マスを自動採掘
* 196チャンク（14×14）　1秒ごとに5×5マスを自動採掘
* 225チャンク（15×15）　0.5秒ごとに5×5マスを自動採掘
